# tw2rss
### Twitter to RSS generator

Requires auth_token(s)

```
GGI script - Generate RSS feed from twitter user
query parameters:
  u = username
  l = limit of items (max/default is 20)
  r = for all tweets and replies
defaults to @nasa and no replies
ex: http://host/cgi-bin/tw2rss?u=NWS&r=1&l=10 
```
